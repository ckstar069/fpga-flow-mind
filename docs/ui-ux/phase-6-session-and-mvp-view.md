# Phase 6 Session 管理与 MVP 验收 UI/UX 设计

---
status: draft
updated: 2026-06-14
---

> 本文档定义 Phase 6 的 session 管理 UI/UX 设计：最近项目列表、保存状态、加载入口、加载失败/版本不兼容/目标路径不存在/checksum mismatch 的展示。同时定义 MVP 总体验收的桌面 UI 流程。
>
> 本文档为 draft，仅供评审与讨论。

## 1. 整体布局

继续以当前 `WorkspacePage` 工作流为主，不做独立 landing page，不做复杂 dashboard。

```text
WorkspacePage
├── 顶部标题栏（新增）
│   ├── 应用名称
│   ├── 当前项目路径
│   └── 保存状态图标
├── 左侧：WorkspaceSummary + StageList（与 Phase 5 一致）
│   └── 新增：最近项目入口
└── 右侧：StageDetail（与 Phase 5 一致）
```

## 2. 顶部标题栏

### 2.1 内容

- 左侧：应用名称 `fpga-flow-mind`。
- 中间：当前项目路径（可截断显示）。
- 右侧：保存状态图标与最后保存时间。

### 2.2 保存状态

| 状态 | 视觉 |
|------|------|
| 已保存 | 绿色圆点 + “已保存” |
| 保存中 | 旋转 spinner + “保存中...” |
| 保存失败 | 红色圆点 + “保存失败” + 重试按钮 |
| 未保存（首次打开未分析） | 灰色圆点 + “未保存” |

## 3. 最近项目入口

### 3.1 位置

位于左侧 `WorkspaceSummary` 下方，标题为“最近项目”。

### 3.2 内容结构

```text
最近项目
├── 项目项 1
│   ├── 项目名称
│   ├── 路径（截断）
│   └── 最后更新时间
├── 项目项 2
│   └── ...
└── “打开其他项目...” 按钮
```

### 3.3 项目项状态

| 状态 | 视觉 |
|------|------|
| 可加载 | 正常样式，可点击 |
| 目标路径不存在 | 灰色 + 警告图标 |
| 目标项目已变更 | 黄色 + 刷新图标 |
| manifest 损坏 | 灰色 + 错误图标 |
| 版本不兼容 | 灰色 + 错误图标 |

### 3.4 操作

- 点击可加载项：加载该 session，恢复 WorkspacePage 状态。
- 点击“打开其他项目...”：打开系统文件选择器，与 Phase 1 一致。
- 右键项目项：出现“删除此记录”菜单。

## 4. 加载入口

### 4.1 首次启动

左侧“最近项目”区域为空，显示占位文案：

> 暂无最近项目，点击“打开其他项目”开始分析。

### 4.2 应用启动时检测到最近 session

可选行为（由实现计划决定默认开启或关闭）：
- 自动加载最近一次成功保存的 session。
- 或仅高亮最近项目，由用户点击加载。

MVP 建议默认不自动加载，避免目标项目变更后给用户意外；可在实现计划中讨论。

## 5. 加载失败状态

### 5.1 目标路径不存在

```text
┌─────────────────────────────┐
│ ⚠️ 无法加载项目              │
│                             │
│ 目标路径已不存在或无法访问：  │
│ /path/to/project            │
│                             │
│ [重新选择路径]  [删除此记录]  │
└─────────────────────────────┘
```

### 5.2 目标项目已变更

```text
┌─────────────────────────────┐
│ ⚠️ 项目文件已变更            │
│                             │
│ 自上次分析以来，目标项目文件  │
│ 已发生变化。历史产物可能不准确。│
│                             │
│ [仅查看历史产物]  [重新分析]  │
└─────────────────────────────┘
```

### 5.3 版本不兼容

```text
┌─────────────────────────────┐
│ ❌ 无法加载此记录            │
│                             │
│ 持久化产物版本与当前应用不兼容。│
│ 建议删除旧记录后重新分析。    │
│                             │
│ [删除此记录]                 │
└─────────────────────────────┘
```

### 5.4 Manifest 损坏

```text
┌─────────────────────────────┐
│ ❌ 记录文件损坏              │
│                             │
│ 无法解析此 session 的元数据。 │
│                             │
│ [删除此记录]                 │
└─────────────────────────────┘
```

## 6. 删除确认

删除最近项目记录时，弹出二次确认：

```text
确定删除此记录？

项目名称：fpga-flow-mind-phase5-acceptance-...
目标路径：/tmp/...

此操作仅删除应用内的持久化记录，不会删除目标项目文件。

[取消]  [删除]
```

## 7. MVP 总体验收 UI 流程

### 7.1 验收项目

复用 `/tmp/fpga-flow-mind-phase5-acceptance-20260614-113748` 或新建 Phase 6 验收项目。

### 7.2 验收步骤

| 步骤 | 操作 | 预期 UI 表现 |
|------|------|-------------|
| 1 | 打开项目，选择 L0，收集证据，生成理解，生成视图 | 与 Phase 5 一致 |
| 2 | 关闭应用 | 顶部保存状态显示“已保存” |
| 3 | 重新打开应用 | 左侧“最近项目”显示该项目 |
| 4 | 点击最近项目 | WorkspacePage 恢复上次状态：阶段选择、evidence、理解、视图 |
| 5 | 查看追溯详情与问答历史 | TracePanel、SourceExcerptPanel、问答区域与上次一致 |
| 6 | 修改目标项目文件 | — |
| 7 | 重新打开应用并加载该项目 | 弹出“项目文件已变更”提示 |
| 8 | 选择“仅查看历史产物” | 加载历史状态，但 UI 显示“项目已变更”警告 |
| 9 | 选择“重新分析” | 清空当前阶段产物，用户需重新收集证据/生成理解 |
| 10 | 删除最近项目记录 | 记录从列表消失，目标项目文件不受影响 |

## 8. 视觉语义

- 沿用 Phase 5 的 confidence 颜色与标签。
- 保存状态使用小圆点 + 文案，不打扰主工作流。
- 最近项目列表使用紧凑卡片，信息层级：项目名称 > 路径 > 时间。
- 错误/警告使用与现有 UI 一致的黄色/红色提示卡片。

## 9. 明确不要做

- 不做独立 landing page。
- 不做复杂 dashboard、统计图表、项目对比。
- 不做自动同步、云登录、协作头像。
- 不做 UI 主题切换、窗口布局拖拽。
- 不保存 UI 滚动位置、窗口大小、分屏比例。
- 不在 UI 中出现 PASS/HOLD/正确/错误/审计等结论。
