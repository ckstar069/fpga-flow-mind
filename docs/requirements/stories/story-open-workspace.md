# Story: 打开业务项目

---
status: draft
updated: 2026-06-11
---

## 用户目标

作为 FPGA 开发人员，我希望通过 `fpga-flow-mind` 打开一个本地业务项目，以便开始理解该项目在各阶段的实现。

## 业务背景

AI Agent 分阶段推进后生成的代码分布在业务项目目录中。用户首先需要让工具识别出这是一个合法的业务项目，并了解其阶段结构和文件分布，才能进行后续理解。

## 前置条件

- 用户本地存在一个由 `ai_project_template` 创建的业务项目目录
- 用户对该项目有读取权限
- `fpga-flow-mind` 已启动（桌面应用已运行）

## 触发入口

用户点击"打开项目"按钮或菜单项，触发文件/目录选择对话框。

## 主流程

1. 用户通过文件选择器选择业务项目根目录
2. 系统验证路径可读性
3. 系统扫描目录结构
4. 系统判断是否为合法业务项目
5. 系统生成 workspace profile
6. 系统展示 workspace 概览

## 功能点清单

### WS-001 目录选择

- **用户动作**：用户通过系统文件选择器选择目录路径
- **系统必须**：弹出原生文件选择对话框，仅允许选择目录（不允许选择单个文件）
- **成功结果**：用户选定一个目录路径，系统记录该路径
- **失败表现**：用户取消选择，保持当前状态，不报错
- **evidence 要求**：不需要
- **MVP 必须**：是

### WS-002 路径可读性检查

- **系统动作**：检查选定路径是否存在、是否为目录、当前进程是否有读权限
- **系统必须**：验证路径存在、是目录、可读
- **成功结果**：路径通过验证，继续扫描
- **失败表现**：弹出错误提示，说明原因（路径不存在 / 不是目录 / 无读权限），允许用户重新选择
- **evidence 要求**：不需要
- **MVP 必须**：是

### WS-003 目录结构扫描

- **系统动作**：递归扫描选定目录下最多 3 层深度，识别文件类型和目录模式
- **系统必须**：
  - 识别阶段目录（如 L0、L1、...、L6、RTL 等命名模式）
  - 识别 Python 文件（`.py`）、Verilog/SystemVerilog 文件（`.v`、`.sv`）
  - 识别文档文件（`.md`、`.rst`、`.txt`）
  - 识别测试文件（`test_*.py`、`*_tb.v`、`*_test.v`）
  - 识别配置文件（`.json`、`.yaml`、`.yml`、`.toml`）
  - 识别外部模块引用标志（如 `urban_wireless` 的导入语句、子模块目录）
- **成功结果**：生成文件类型统计和阶段候选列表
- **失败表现**：扫描失败时提示"无法读取目录内容"，允许用户重新选择
- **evidence 要求**：不需要（此阶段为系统扫描动作）
- **MVP 必须**：是

### WS-004 合法性判断

- **系统动作**：基于扫描结果判断该项目是否可能是 `ai_project_template` 创建的业务项目
- **系统必须**：
  - 检查根目录下是否存在预期的阶段目录或阶段标识文件
  - 检查是否同时存在 Python 和/或 Verilog 文件
  - 给出判断结果：`likely_valid`（符合模板特征）、`uncertain`（部分特征匹配）、`unlikely`（不符合特征）
- **成功结果**：展示判断结果，允许用户继续（即使是 `unlikely` 也允许用户强制继续）
- **失败表现**：无硬性失败，仅提示风险等级
- **evidence 要求**：不需要
- **MVP 必须**：是

### WS-005 生成 workspace profile

- **系统动作**：基于扫描结果生成 workspace profile
- **系统必须**：
  - 记录 workspace 名称（目录名）
  - 记录根路径（绝对路径）
  - 记录候选阶段列表（目录名 + 路径 + 文件数量统计）
  - 记录文件类型统计（Python 数、Verilog 数、文档数、测试数、配置数）
  - 记录外部模块引用标识（如有）
  - 记录扫描时间戳
- **成功结果**：workspace profile 已生成，可用于后续阶段选择
- **失败表现**：生成失败时提示用户重新扫描
- **evidence 要求**：profile 中的每个阶段引用应包含 source path
- **MVP 必须**：是

### WS-006 展示 workspace 概览

- **系统动作**：在主界面展示 workspace 概览面板
- **系统必须**：
  - 显示 workspace 名称和根路径
  - 显示候选阶段列表（可点击选择）
  - 显示文件类型统计（数字或简单图表）
  - 显示风险/不确定项（如阶段缺失、命名异常、无代码文件等）
  - 显示外部模块引用标识（如有）
- **成功结果**：用户可看到项目概览并准备选择阶段
- **失败表现**：无数据时显示空状态提示
- **evidence 要求**：阶段列表中的每个阶段应关联 source path
- **MVP 必须**：是

### WS-007 安全边界执行

- **系统动作**：确保扫描过程中不写入目标项目目录
- **系统必须**：
  - 仅执行读取操作（`read_dir`、`read_file`）
  - 不创建、不修改、不删除目标项目中的任何文件或目录
  - 所有中间产物写入 app-owned 目录或临时目录
- **成功结果**：目标项目目录内容无变化
- **失败表现**：如意外触发写入操作，应中止并报错
- **evidence 要求**：不需要
- **MVP 必须**：是

## 输入

| 输入项 | 来源 | 类型 |
|--------|------|------|
| 项目根目录路径 | 用户通过文件选择器选择 | 文件系统路径 |

## 输出

| 输出项 | 类型 | 说明 |
|--------|------|------|
| workspace_profile.json | 结构化数据 | 包含 workspace 名称、根路径、阶段列表、文件统计、风险项 |
| 界面展示 | UI 状态 | workspace 概览面板 |

## 异常 / 空状态

| 场景 | 处理 |
|------|------|
| 路径不存在 | 提示"路径不存在"，允许重新选择 |
| 路径不是目录 | 提示"请选择一个目录"，允许重新选择 |
| 无读权限 | 提示"无法读取该目录，请检查权限"，允许重新选择 |
| 目录为空 | 提示"该目录为空"，允许重新选择 |
| 无阶段目录 | 提示"未识别到阶段目录，是否继续？"，允许用户强制继续 |
| 无代码文件 | 提示"未找到 Python 或 Verilog 文件"，允许用户强制继续 |
| 扫描超时 | 提示"目录扫描超时，可能目录过大"，允许重新选择或调整路径 |

## 证据与追溯要求

- workspace profile 中的阶段列表必须包含每个阶段的 source path（绝对路径）
- 外部模块引用标识应包含来源路径或引用位置

## 不确定性表达要求

- 合法性判断结果应明确标注（`likely_valid` / `uncertain` / `unlikely`）
- 对于 `uncertain` 和 `unlikely` 的情况，应列出不匹配的具体原因
- 不应将 `uncertain` 呈现为确定结论

## MVP 验收标准

- [ ] 用户能通过文件选择器选择目录
- [ ] 系统验证路径可读性并给出清晰错误提示
- [ ] 系统识别阶段目录和文件类型
- [ ] 系统给出合法性判断（不阻止用户继续）
- [ ] workspace profile 包含名称、路径、阶段列表、文件统计
- [ ] workspace 概览面板正确展示上述信息
- [ ] 扫描过程中不写入目标项目目录
- [ ] 空项目和异常路径有恰当提示

## 非目标

- 不自动推断项目模板版本号
- 不解析项目内部依赖关系（留到 evidence 收集阶段）
- 不做代码语法检查
- 不修改目标项目目录结构
